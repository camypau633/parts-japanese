# Parts Japanese

Экспериментальная база японских OEM-каталогов для PartScope.

## Источник

- Каталог: https://www.catcar.info/
- Toyota/Lexus: https://www.catcar.info/toyota/
- На первом этапе используется рынок Japan.
- Данные собираются по иерархии каталога, а не по случайным поисковым запросам.

## Проверенная структура CatCar

На примере Toyota 86 (каталог 264110, модификация ZN6-A288) подтверждены уровни:

1. Марка / каталог.
2. Рынок (Japan, Europe, Middle East, USA).
3. Модельный каталог: код, модель, период производства, модификации.
4. Конкретная модификация: код, двигатель, период, комплектация/трансмиссия.
5. Группы деталей: двигатель/топливо, трансмиссия, кузов, электричество.
6. Подгруппы/иллюстрации: например, 15-02 «Фильтр масляный».
7. Строки деталей, связанные с иллюстрацией.

## Целевой формат

Пока это спецификация, не готовая выгрузка каталога. Перед массовым импортом необходимо проверить получение исходного HTML и изображений из среды GitHub Actions и определить точные поля строк деталей и координаты/позиции на схемах.

Планируемые сущности:

- `vehicles`: рынок, марка, модель, код каталога, годы, модификации.
- `groups`: группы и подгруппы деталей, родительские связи.
- `diagrams`: идентификатор схемы, исходный URL изображения, привязка к подгруппе.
- `parts`: OEM-номер, наименование, количество, номер позиции на схеме.
- `part_applications`: связь детали с применимостью к конкретным каталогам/модификациям.

## Важные ограничения

- Не считать наличие страницы в браузере доказательством доступности массовой выгрузки из GitHub Actions.
- Не считать, что Playwright или смена User-Agent гарантированно обходит ограничения сайта.
- Не запускать полный обход до успешного теста на одном каталоге и проверки изображений.
- Не добавлять выдуманные OEM-номера, связи или характеристики.
