# Parts Japanese / CatCar Extraction POC

Экспериментальный проект по исследованию структуры каталогов CatCar и проверке возможности извлечения данных для последующей нормализации в PartScope.

## Текущий статус

Это пока **исследовательский POC**, а не готовый импортёр и не полная база запчастей. Массовый сбор не запускается.

Проверены отдельные страницы четырёх семейств каталогов:

| Семейство | Проверенный пример | Особенность |
|---|---|---|
| Toyota | 86 / Camry | AJAX-раскрытие строк, отдельные OEM-вариации и применимость |
| Nissan | Pixo (UA0) | Статическая таблица; связь позиции со схемой через `srcNum` |
| Ford | Fiesta DX 1995–2002 | Иерархия групп; позиция схемы связана с колонкой `Code` |
| Volkswagen / VAG | Campmob. (Typ2/Transp./LT), 2018 | Общий каталог Audi/VW/Skoda/Seat; статическая таблица с вариантными строками |

Эти проверки подтверждают, что единого HTML-парсера недостаточно. Нужны отдельные адаптеры источников и общий нормализованный формат.

## Документы исследования

- `docs/catcar-camry-stage-a-validation.md` — проверка Toyota Camry: AJAX и OEM-записи.
- `docs/catcar-oem-temporal-validation.md` — пересечения периодов OEM; автоматическую замену номеров не выводим.
- `docs/catcar-nissan-cross-brand-validation.md` — проверка Nissan Pixo.
- `docs/catcar-ford-third-brand-validation.md` — проверка Ford Fiesta.
- `docs/catcar-vw-fourth-brand-validation.md` — проверка Volkswagen / VAG.
- `docs/catcar-normalized-extraction-contract-draft.md` — черновик общей структуры данных.
- `docs/catcar-access-policy-discovery.md` — robots.txt и поиск опубликованных условий.
- `tools/catcar_poc/README.md` — описание начального каркаса адаптеров и ограничений.
- `schemas/catcar-extraction-v0.1.schema.json` — черновая JSON Schema общего формата.

## Текущая реализация

- Добавлен общий HTML-парсер и четыре адаптера: Toyota, Nissan, Ford и VAG.
- Добавлена нормализация в черновой единый JSON-формат.
- Toyota AJAX-записи сохраняют связь с исходной строкой; пустые поля периода и применимости не сдвигают соседние значения.
- Проверяется соответствие результата JSON Schema.
- GitHub Actions выполняет тесты на Python 3.12; локальная настройка компьютера не требуется.
- Последняя проверка `CatCar adapter unit tests` прошла успешно.

Это пока каркас парсинга и нормализации на синтетических тестах, а не проверенный на полных сохранённых HTML-страницах промышленный импортёр.

## Основные правила извлечения

1. Сохранять исходные значения и порядок строк.
2. Не считать любой отображаемый номер подтверждённым OEM-номером.
3. Не объединять несколько OEM-записей и не выводить замену по одним только датам.
4. Сохранять строки без применимости и неразрешённые обозначения схем.
5. Сопоставлять позиции схем с таблицей и отдельно фиксировать несовпадения.
6. Сохранять исходные координаты hotspot и URL схемы.
7. Не наследовать номер позиции для строк-продолжений без подтверждения структуры источника.

## Следующие этапы

1. Уточнить у оператора CatCar, разрешены ли автоматизированное извлечение и повторное использование данных. `robots.txt` задаёт Crawl-delay 10 секунд, но не является лицензией; на главной странице условия использования не найдены.
2. Уточнить неразрешённые особенности строк-продолжений VAG и таблиц других семейств.
3. Зафиксировать контракт нормализованного JSON.
4. Подключить реальные HTML-фикстуры из проверенных страниц и сравнить результаты адаптеров с ранее подтверждёнными подсчётами строк и hotspot.
5. После прохождения фикстур завершить контракт JSON и добавить безопасную обработку каталожной навигации и AJAX-ответов.
6. Только после отдельного решения по разрешению — реализовывать ограниченный импорт и экспорт для PartScope.


## Ограничения

- Проверка одной страницы не доказывает поддержку всех моделей, лет, рынков и вариантов каталога.
- Наличие данных в браузере не доказывает разрешение или техническую возможность массового сбора.
- Не обходить ограничения доступа и не запускать массовые запросы без отдельной проверки условий использования.
